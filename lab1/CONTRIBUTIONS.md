Артем:
1. Интерфейс программы
    • делает окно на PуQtб ;
    • добавляет поля Input window, Output window , Status
    window;
    • делает выпадающие списки для выбора СОМ-портов;
    • настраивает стили интерфейса.


Авелина:
2. Работа с СОМ-портами
    • ищет доступные СОМ-порты;
    • открывает порт для отправки и порт для приема;
    • следит, чтобы один и тот же порт не выбирался дважды;
    • выводит параметры порта: скорость, биты данных, четность,
    stop bits и т.д.


Антон:
3. Отправка данных
    • обрабатывает ввод пользователя;
    • разрешает ввод только е и 1;
    • собирает введенные биты в блоки;
    • отправляет готовый кадр через выбранный СОМ-порт.


Слава:
4. Формирование кадра и bit-stuffing
    • формирует структуру кадра: флаг, адрес назначения, адрес
    источника, данные, FCS;
    • добавляет флаг 10001110 ;
    • реализует bit-stuffing;
    • выделяет добавленные биты в окне статуса.


Кристина:
5. Прием, восстановление данных и тестирование
    • принимает данные со второго СОМ-порта;
    • выполняет debit-stuffing, то есть удаляет добавленные биты;
    • извлекает полезные данные из кадра;
    • проверяет работу программы на виртуальных СОМ-портах;
    • оформляет отчет: цель, алгоритм, скриншоты, вывод.
