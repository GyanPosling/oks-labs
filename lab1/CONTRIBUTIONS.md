# Распределение обязанностей

Лабораторная работа N1, вариант 2.

Основные требования варианта:

- выбираемый параметр COM-порта: длина байта;
- остальные параметры COM-порта фиксированы;
- передача сообщений выполняется построчно, после нажатия Enter;
- данные передаются через COM-порт посимвольно;
- интерфейс содержит окна управления, ввода, вывода и состояния.

## Артем

### 1. Интерфейс программы

- делает окно на PyQt6;
- добавляет поля Input window, Output window и Status window;
- делает выпадающий список для выбора COM-порта;
- добавляет выпадающий список для выбора размера байта;
- настраивает стили интерфейса.

## Авелина

### 2. Работа с COM-портами

- ищет доступные COM-порты;
- открывает выбранный COM-порт;
- настраивает фиксированные параметры порта: скорость 9600, четность none и 1 stop bit;
- применяет выбранный пользователем размер байта;
- блокирует изменение параметров после открытия порта.

## Антон

### 3. Отправка данных

- обрабатывает ввод пользователя;
- отправляет сообщение после нажатия Enter;
- передает введенную строку через выбранный COM-порт посимвольно;
- очищает поле ввода после отправки;
- выводит информацию об отправленном сообщении в окно статуса.

## Слава

### 4. Прием данных

- создает отдельный поток для чтения данных из COM-порта;
- проверяет наличие входящих данных;
- декодирует принятые байты в текст;
- выводит принятые данные в Output window без блокировки интерфейса.

## Кристина

### 5. Статус, обработка ошибок и тестирование

- выводит в Status window выбранные параметры порта;
- считает количество отправленных символов;
- обрабатывает ошибки открытия, отправки и приема данных;
- проверяет работу программы на виртуальном или реальном COM-порте;
- подготавливает материалы для отчета: цель, алгоритм, скриншоты, вывод.
