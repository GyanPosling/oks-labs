## Работа с Git

### Создать новую ветку и переключиться на нее

```bash
git checkout -b имя-ветки
```

Пример:

```bash
git checkout -b lab1
```

### Переключиться на существующую ветку

```bash
git checkout имя-ветки
```

Пример:

```bash
git checkout main
```

### Отправить ветку на GitHub

Если ветка отправляется первый раз:

```bash
git push -u origin имя-ветки
```

Если ветка уже была отправлена раньше:

```bash
git push
```

### Создать Pull Request

1. Открыть репозиторий на GitHub.
2. Перейти во вкладку **Pull requests**.
3. Нажать **New pull request**.
4. Выбрать свою ветку и ветку, в которую нужно добавить изменения.
5. Проверить список изменений.
6. Нажать **Create pull request**.

### Получить свежие изменения из удаленного репозитория
(для того, если кто-то что-то закомитил, а у тебя локального этого нету)

```bash
git pull
```
